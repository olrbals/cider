# 1950 → 2024 3D 히스토리 1차 프로토타입

## 실행

프로젝트 루트에서 `node experiments/serve-local.mjs`를 실행하고 `http://127.0.0.1:8767/index.html#history-3d`에 접속합니다.

## 구성

- `js/history-3d.js`의 `HISTORY_ERAS` 배열이 연도, 피그마 배경, 패키징 UV, WebGL 대체 이미지를 관리합니다.
- 하나의 Three.js 캔 모델을 유지하고, 기존 `blendLabels()` 방식으로 인접한 두 라벨을 스크롤 위치에 맞춰 혼합합니다. 라벨과 배경의 전환 구간은 같습니다.
- 1950 → 1960 구간의 두 바퀴 롤링과 이동 폭을 이후 구간에도 연속으로 반복합니다. 캔의 긴 축은 계속 가로 방향입니다.
- 기존 1970~2024 정적 캔 장면은 중복 노출을 막기 위해 히스토리 흐름에서 제거했습니다. WebGL을 사용할 수 없으면 해당 연도의 제품 이미지가 대신 나타납니다.

## 피그마 원본과 UV

8개 배경과 기존 1950·1960 패키징은 피그마 원본과 픽셀 단위로 일치합니다. 추가한 1970·1987·1994·2000·2014·2024 패키징은 피그마 원본의 1774×887 픽셀, 2:1 비율을 그대로 저장했습니다.

2014·2024 원본의 양 끝 색상 차이는 원통 이음새에서 보일 수 있습니다. `scripts/prepare-history-uv.py`로 이미지 양 끝 5% 범위만 부드럽게 연결한 `-uv.png`를 만들었으며, 원본 PNG는 보존했습니다. 2000·2024 라벨은 원본 그림을 수정하지 않고 UV 시작 위치만 조정해 전면 그림을 보이게 했습니다.

## 확인 결과와 피드백 포인트

1440×900 Chrome에서 8개 연도 순서, 역스크롤, 중간 라벨 혼합, 제품 버튼, 커서 액체 굴절과 WebGL 동시 동작, WebGL 미지원 시 1950·2024 대체 이미지를 확인했습니다. 2024년 원본 로고는 원통 곡면을 따라 감기므로 캔 정면에서 일부 글자가 곡면 가장자리로 넘어갑니다. 라벨의 원본 비율은 유지했으며, 이 표현은 1차 피드백 대상입니다.
