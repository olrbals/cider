# Rolling Can Animation

Blender에서 **가로로 누운 캔이 제자리에서 4초 동안 한 바퀴 회전하는** 테스트 프로젝트입니다.

## 집에서 이어서 작업하기

1. [rolling_can.py](./rolling_can.py)를 열고 **Raw** 버튼을 누른 다음 파일을 저장하세요 (또는 코드를 복사하세요).
2. Blender를 열고 **File → New → General**을 선택하세요.
3. 상단의 **Scripting → New**에 코드를 붙여 넣고 **Alt + P**를 누르세요. (기존 씬의 오브젝트를 모두 지우니 반드시 새 파일에서 실행!)
4. **Layout**으로 돌아가 숫자패드 **0**을 눌러 카메라 시점으로 보고, **스페이스바**로 재생하세요.
5. **File → Save As...**로 `rolling_can_v01.blend`를 저장하세요.

### 상태
- [x] 기본 캔 생성
- [x] 제자리 X축 회전 (4초 / 30fps / 120프레임)
- [x] 카메라 및 조명
- [ ] 패키징 디자인 A → B → C 부드러운 전환 (다음 작업)

> **중요:** `rolling_can.py`는 Blender 씬을 재생성하는 코드입니다. 지금 컴퓨터에서 저장한 **실제 `.blend` 프로젝트 파일**은 자동 업로드되지 않습니다. 완전히 똑같은 편집 상태를 보존하려면 Blender에서 Save As로 저장한 뒤 GitHub에도 해당 파일을 직접 업로드해 주세요.
